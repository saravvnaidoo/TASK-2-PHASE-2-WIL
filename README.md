# Next Level Gaming & Esports Arena - Mobile App

A phone-first browser app where players can explore the arena, view the Competitive PC Package, estimate session fees and send a contact enquiry.

## Screens

1. **Home** - arena highlights, quick links to packages and fees
2. **About Us** - venue backstory
3. **Overview** - PC, console, VIP and tournament options
4. **Package** - Competitive PC Package breakdown
5. **Calculate Fees** - interactive pricing tool
6. **Contact Us** - venue address, phone, email, contact form

## Tech Stack

- HTML5, CSS3, vanilla JavaScript (no frameworks)
- Figma (wireframes)
- GitHub (version control)
- VS Code + Live Server (development & testing)

## Run and Test

Open this folder in VS Code and click **Go Live** from `index.html`. To preview a phone-sized screen in Chrome, open DevTools (F12) and press **Ctrl+Shift+M**. To test on a real phone, connect it to the same WiFi and open the local IP address Live Server shows.
